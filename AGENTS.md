# Project Instructions

## Cross-Session Handoff

- At the start of project work, read [`HANDOFF.md`](HANDOFF.md) when it exists.
- If context, decisions, procedures, intermediate results, measurements, test data, or unfinished work must survive the current conversation session, record them in `HANDOFF.md`.
- Keep handoff entries concise, dated, actionable, and current; update or remove stale information.
